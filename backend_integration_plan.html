Backend Integration Plan

MediGenius v1.0 • Technical Requirements for Patients & Scheduling

1. Patient Management Resources

Method Endpoint Description
GET /patients/getAllPatients Fetch full registry for Admin User Management.
POST /patients/addPatient Identity Provider: Create new patient record (Name, Email, DOB).
GET /patients/getPatientById/:id Full profile retrieval for Doctor/Admin view.
PUT /patients/updatePatient/:id Update profile details or identity verification status.
DELETE /patients/deletePatient/:id Deactivate patient account.

2. Clinical Records & History

Method Endpoint Description
GET /patients/:id/medicalRecords Retrieve all clinical reports, labs, and imaging for a patient.
POST /patients/:id/addRecord Upload/Create a new clinical report or session note.

3. Scheduling & Availability

Method Endpoint Description
GET /doctors/:id/availability Fetch doctor's weekly work hours and slot intervals.
PUT /doctors/:id/availability Save/Update master weekly availability schedule.
GET /appointments/doctorSchedule/:id Current bookings list for Doctor Dashboard calendar.
GET /appointments/available-slots Query free intervals for booking based on availability.

4. Booking Lifecycle

Method Endpoint Description
POST /appointments/book Initialize new visit booking entry.
PATCH /appointments/status/:id Cycle status: Confirmed → Arrived → In Progress → Completed.
GET /appointments/patientHistory/:userId Retrieve patient-specific visit history (Upcoming & Past).
